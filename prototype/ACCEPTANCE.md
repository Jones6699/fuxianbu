## 三、已实现的交互（可完整点通）

- **发送/停止**：工具栏、输入区、`.compose textarea`、Send ▲（无 API Key 时禁用并 toast 提示；生成中 ▲ 变 ■ 可停止）。
- **流式模拟**：`streamIn()` 逐字回填 + 闪烁省略号；完成后若开启自动检查触发 CheckerBar。
- **消息操作**：✓ 文风检查（得分条 + 档位）、✎ 编辑、□ 存草稿、❝ 提取、⧉ 复制、✗ 删除（二次确认）。
- **版本切换**：bot 消息 `<1/N>` 上/下切换。
- **知识库**：6 标签、条目注入 `{{kb:…}}`、全部注入、拖拽调整高度、注入计数标注。
- **结构体/局部补写**：工具栏开关、[2][3][4] 数量、前缀/后缀。
- **历史侧栏**：项目展开收起、重命名、删除（确认）、克隆对话、新对话/新项目。
- **搜索**：项目+对话标题实时过滤、命中跳转。
- **设置**：主题暗/亮实时切换、提供商、API Key、温度、禁词、字号、开关项。
- **空态**：无消息对话 →「输入内容，开始创作」。

## 四、与规格的差异记录（§15.3 默认决策）

| 决策 | 说明 |
|---|---|
| 提取符号用 `❝` | §12.2 建议 `"`；为区分消息内容与符号，采用 `❝`，语义 ID `icon.extract` 不变 |
| 演示原型默认无 API Key | 发送钮初始禁用，需到设置填入 Key 解锁，符合 §13「无 API Key 发送」边界 |
